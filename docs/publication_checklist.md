# Publication checklist — author review required

Before uploading this *public* repository:

1. Confirm that publishing the manuscript **while under revision** is consistent with journal and any double-blind review requirements.
2. Review the writing-sample PDF for interview quotes, potentially identifying institutional details, personal academic email and permission to publish participants' words.
3. Confirm that voluntary, anonymous survey consent/ethics approval included **public release of respondent-level data**, not merely aggregated publication. If not, keep the raw CSV private and adjust this repository to distribute aggregated outputs only.
4. Reconcile the source material's stated **CC BY 4.0** notice with the desired per-file public licensing statement; no repository-wide new licence has been imposed.
5. Ensure the source sample sizes and item codebook remain consistent with the manuscript's current revision.
6. Run GitHub Actions with R/Quarto and inspect the generated numerical tests before representing the repo as fully R-reproduced.
7. Do not place the companion **private evidence ZIP** inside the GitHub repository.

Published numerical associations should be described as **perception-based correlations**, never as measured fund performance or causal effects.
